
# Student Bio-Data Form

## Project Overview

The Student Bio-Data Form is a simple web application that allows students to enter their personal and academic information through an online form.

This project was developed as part of a group assignment for VUA-SEN-305. It demonstrates the use of HTML, CSS, JavaScript, and collaborative development with Git and GitHub.

## Features

- Student personal information collection
- Academic information collection
- Required field validation
- Email input validation
- Submit and clear form buttons
- Responsive user interface (implemented through CSS)
- Client-side form interaction using JavaScript

## Technologies Used

- **HTML5:** Structures the form and its input fields.
- **CSS3:** Styles the form and improves its appearance.
- **JavaScript:** Handles form validation and submission feedback.
- **Git:** Tracks changes to the source code.
- **GitHub:** Hosts the repository and supports team collaboration.

## Form Fields

### Personal Information

- Full Name
- Matriculation Number
- Email Address
- Phone Number
- Date of Birth
- Gender

### Academic Information

- Department
- Level

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/KelvinJ-cyber/VUA-SEN-305-Group-19.git
   ```

2. Navigate into the project folder:

   ```bash
   cd VUA-SEN-305-Group-19
   ```

3. Open `form.html` in your web browser.

   Alternatively, open the folder in Visual Studio Code and use the Live Server extension.
